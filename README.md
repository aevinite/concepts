# Aevinite concepts

Ten concept versions of aevinite.com plus the old (11) and current (12) site, for choosing the
next design. Published at https://aevinite.github.io/concepts/ (not indexed by search engines).

- `PLAN.md` — what each concept is, and the rules they all follow.
- `shared/content.ts` — every fact the concepts may say.
- `sites/<n>/` — one concept each (Vite, vanilla TypeScript).
- `SITE=<n> npx vite --port 51<nn>` to run one; `node scripts/look.mjs <n>` to screenshot it.
- `npm run build` builds everything into `dist/`; pushing to `main` publishes it.
